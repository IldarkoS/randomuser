## Приложение для взаимодействия с API: https://randomuser.me/api/

### Инструкция по запуску:
1. Склонировать репозиторий.
2. В корне проекта `make up`.

2. Переименовать файл `example.env` в `.env`. В корне проекта выполнить команду `docker compose up --build` (fastapi перезапускается, так как стартует раньше, чем база данных).
