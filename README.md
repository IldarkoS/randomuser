## Приложение для взаимодействия с API: https://randomuser.me/api/

### Инструкция по запуску:
1. Склонировать репозиторий.
2. Переименовать файл example.env в .env 
3. В корне проекта выполнить команду docker compose up --build (fastapi перезапускается, так как стартует раньше, чем база данных)
4. Приложение будет доступно на страницe localhost:8000/
5. Документация на странице localhost:8000/docs

В качестве фреймворка был выбран FastAPI из-за своей простоты, асинхронности, автоматически генерируемой документации.
